# Wayfarer — Personalized Travel Itinerary Planner

A React + FastAPI travel planner that turns your destination, dates, budget, and interests into a day-by-day itinerary.

## Run locally

See the full setup guide and architecture in this repository. The frontend uses Vite; the API runs with FastAPI on port 8000.

## Project status

This is an individual learning project prototype. AI generation works with an optional server-side OpenAI API key; without a key, the API returns a demo itinerary. Supabase schema is included for optional trip persistence.
